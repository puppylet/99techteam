## 🚀 Getting Started

### 1. Installation

- Requirements: Node.js (version 18 or higher, latest LTS recommended)

- Install necessary dependencies (standard Node.js setup):

```bash
npm install
```

### 2\. Running the Solutions

The `package.json` file is configured with the following scripts:

#### Problem 1: Three ways to sum to n

Run the interactive Command Line Interface (CLI). It will prompt for a method (Loop, Reduce, or Math Formula) and the number $N$.

```bash
npm run problem1
```

#### Problem 2: Fancy Form

Run the Problem 2 solution (assuming the code is executable):

```bash
npm run problem2
```
